## 📌 Project Overview
Proyek ini bertujuan untuk memprediksi harga rumah di California berdasarkan dataset **California Housing**. Dalam proyek ini, saya mengeksplorasi penggunaan algoritma **Multiple Linear Regression** untuk memahami hubungan antara berbagai fitur (seperti lokasi, pendapatan median, usia rumah, dll.) dengan harga rumah.

Melalui proyek ini, saya mempelajari proses *End-to-End Machine Learning*, mulai dari persiapan data, pembangunan model, melakukan prediksi, hingga melihat korelasi antar data untuk menemukan pola yang memengaruhi harga properti.
